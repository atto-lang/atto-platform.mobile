# Shared mobile contracts

The C11 value-only intent and trusted-host snapshot are shared between iOS and Android. Run `make test` from the repository root. This is a policy oracle, NOT a renderer or an actor scheduler. A returned ADMISSIBLE is not an authorization token. Before every actual native mutation, the platform adapter must reread ownership, generation, permission, scene state, revision and UI thread on that same UI-thread turn. Actor messages must contain scalar/serialized values only; never native view pointers, closures or authority-bearing handles.

The host also owns a bounded queue, unique retired scene IDs, callback cancellation, transactional validation, quarantine on partial mutation, and a fresh authority check after every async hop. This pure check does NOT implement those mechanisms.
